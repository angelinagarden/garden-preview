The Access Layer: The Open Data Backbone Every Researcher Can Reach

Most of the data behind the AI tools everyone pays for is open, free, and reachable directly — if you know where it lives. This is the map.

Two things are tangled together and worth separating. There is the open backbone: canonical databases, archives and APIs across the sciences, social sciences and the humanities — run by universities, nonprofits, libraries and public bodies, free to hit directly. And there are the gateways — Firecrawl, Parallel and their kind — that wrap many of these into one subscription for convenience. Knowing which is which is the whole point: you rarely pay for the data; you pay for the plumbing. Here is the backbone first, then an honest X-ray of what the gateways actually add.

open = free, no key. free-key = free, needs a key. freemium = free tier, then paid. open-source = run it yourself.

01

Open Scholarly Backbone — hit these directly, no gateway

OpenAlex — graph of ~250M works, authors, institutions (open replacement for Scopus). open. openalex.org

Crossref API — canonical DOI and publication metadata. open. api.crossref.org

arXiv API — preprints across physics, maths, CS, bio. open. info.arxiv.org/help/api

Unpaywall — legal open-access full texts by DOI. open. unpaywall.org

Semantic Scholar API — metadata, citations, embeddings, the S2ORC corpus. free-key. api.semanticscholar.org

PubMed & PMC (NCBI) — biomedical literature + open-access full text via E-utilities. open. ncbi.nlm.nih.gov

Europe PMC — life-science literature + full texts, REST. open. europepmc.org

CORE — aggregator of 300M+ open-access full texts. free-key. core.ac.uk

OpenCitations — CC0 citation graph, billions of DOI-to-DOI links. open. opencitations.net

DOAJ — index of 23k+ vetted open-access journals + articles. open. doaj.org/api

OpenAIRE Graph — EU open scholarly graph: pubs, data, software, funding. open. graph.openaire.eu

Lens.org — scholarly works + patents in one search. free-key. lens.org

BASE — 400M+ documents from open repositories worldwide. open. base-search.net

Retraction Watch Database — every known retraction, now open via Crossref. open. retractionwatch.com

Open Data Repositories & Dataset Discovery

Zenodo — open repository for data, software, papers; CERN-backed. open. zenodo.org

Harvard Dataverse — canonical open repository of research datasets. open. dataverse.harvard.edu

Dryad — curated open research data with DOIs. open. datadryad.org

Figshare — open research outputs and datasets. open. figshare.com

re3data — registry of 3000+ research-data repositories. open. re3data.org

Google Dataset Search — search engine across millions of open datasets. open. datasetsearch.research.google.com

Hugging Face Datasets — thousands of ML datasets + rows over API. free-key. huggingface.co

Kaggle Datasets — large catalogue of open datasets and notebooks. free-key. kaggle.com/datasets

Our World in Data — vetted global indicators + CSV downloads. open. ourworldindata.org

World Bank Open Data — 16k+ global development and economic indicators. open. data.worldbank.org

Eurostat API — official EU statistics, machine-readable. open. ec.europa.eu/eurostat

OECD Data — OECD statistics via SDMX API. open. data.oecd.org

03

Open Scientific Databases, by field

NCBI E-utilities — one keyless gateway to 35+ NIH databases (GenBank, dbSNP, Gene). open. ncbi.nlm.nih.gov

UniProt — canonical protein-knowledge API (UniProtKB, ID mapping). open. uniprot.org

PubChem — largest open chemistry DB, 100M+ compounds. open. pubchem.ncbi.nlm.nih.gov

ChEMBL — open database of bioactive drug-like molecules (IC50, Ki). open. ebi.ac.uk/chembl

RCSB PDB — CC0 archive of 254k+ experimental 3D structures. open. data.rcsb.org

AlphaFold DB — 260M+ predicted protein structures (EMBL-EBI / DeepMind). open. alphafold.ebi.ac.uk

Ensembl — genome annotation and comparative genomics across species. open. rest.ensembl.org

GBIF — world biodiversity layer, ~3.96B occurrence records. open. gbif.org

Human Protein Atlas — where every human protein sits, by tissue and cell. open. proteinatlas.org

Open Targets — target-to-disease-to-drug evidence, CC0. open. platform.opentargets.org

KEGG / Reactome / STRING — pathways, reactions and protein-interaction networks. open. reactome.org

ClinicalTrials.gov — registry of studies via public v2 REST API. open. clinicaltrials.gov

04

Social Sciences & Their Data

OSF & OSF Preprints — open projects, data and preprints incl. SocArXiv, PsyArXiv. open. osf.io

SSRN — social-science and humanities preprints, free to read. free-key. ssrn.com

RePEc / EconStor — open economics papers and working papers. open. ideas.repec.org

ICPSR — largest social-science data archive (much open, some restricted). free-key. icpsr.umich.edu

IPUMS — harmonized census and survey microdata, free with registration. free-key. ipums.org

GESIS / UK Data Service — European social-science data archives. free-key. gesis.org

V-Dem — Varieties of Democracy indices and datasets per country-year. open. v-dem.net

World Values Survey — cross-national survey data on values and beliefs. open. worldvaluessurvey.org

05

Books, Libraries & Cultural Heritage

Internet Archive / Open Library — millions of books plus the Open Library API. open. openlibrary.org

HathiTrust — 17M+ volumes; public-domain full text + bibliographic API. open. hathitrust.org

Project Gutenberg (Gutendex) — 70k+ free ebooks via a clean JSON API. open. gutendex.com

Library of Congress API — digitized collections as JSON (loc.gov). open. loc.gov/apis

Europeana — 58M+ cultural-heritage items across Europe, API. free-key. europeana.eu

DPLA — Digital Public Library of America, metadata API. free-key. dp.la

DOAB / OAPEN — directory and library of peer-reviewed open-access books. open. doabooks.org

Google Books API — book metadata, previews and full-text search. free-key. developers.google.com/books

06

World, Web & Knowledge Data

Wikidata — free knowledge graph, SPARQL plus REST. open. query.wikidata.org

OpenStreetMap / Overpass — open world map + a query engine over the full graph. open. overpass-api.de

Common Crawl — open petabyte-scale web archive (WARC). open. commoncrawl.org

Internet Archive / Wayback — keyless index over every web snapshot ever saved. open. archive.org

GDELT 2.0 — largest open event and news DB, 100+ languages. open. gdeltproject.org

EPO Open Patent Services — European and PCT patent data (bibliographic, full-text, legal status). free-key. epo.org

07

The Gateways — what the subscription actually buys

Firecrawl + Alexandria — free plan 1000 credits; catalogue discovery is free. Aggregates 30+ typed providers into one key — but most are the open bases above (arXiv, UniProt, PDB, ChEMBL, Europe PMC); a few are genuinely gated elsewhere (web-traffic intelligence, anti-bot-locked sites). freemium. firecrawl.dev

Parallel — you pay for verified STRUCTURE, not data: answers with inline citations and per-field confidence (Task API), typed JSON output, live web research. freemium. parallel.ai

Jina Reader — any URL to clean LLM-ready markdown via r.jina.ai/<url> — the one genuinely free piece of the plumbing. open. jina.ai/reader

MCP registries — Official Registry + mcp.so: discover ready connectors so an agent plugs any source in as a tool. open. mcp.so

LlamaIndex / LangChain — open-source orchestration and retrievers for RAG. open-source. llamaindex.ai

Vector DBs (free tier) — Qdrant, Weaviate, Chroma, pgvector, Milvus — run retrieval yourself. open-source. qdrant.tech

The line is the lesson. The backbone — arXiv, OpenAlex, UniProt, PDB, Europe PMC, Common Crawl and the rest — is run by institutions and asks nothing. The gateways sell convenience on top: one key, cleaner output, verified structure. Both are worth it in their place. Just know, every time, which one you are actually paying for.
