The Access Layer: 33 Ways an Agent Reaches Data — and What Quietly Went Paid in 2026

Everyone talks about the model. Almost no one talks about the layer underneath it — how an agent actually reaches data.

That layer is where research with AI is won or lost. And in 2026 it is quietly splitting into what stays open and what slips behind a meter. Below: 33 connectors, data-APIs and gateways a researcher — or an agent — can reach right now, grouped by what they do, each marked by how you get in. open = free, no key. free-key = free, needs a key. freemium = free tier, then paid. paid = no real free tier.

01

Search & Retrieval APIs for Agents

Exa — (ex-Metaphor) semantic search + page contents built for LLMs. freemium. exa.ai

Tavily — search API tuned for agents, LLM-ready output. freemium. tavily.com

Perplexity Sonar API — search-grounded answers with citations. paid. docs.perplexity.ai

Brave Search API — independent index, JSON output. freemium (slashed Feb 2026). brave.com/search/api

You.com API — Search / Contents / Answer / Research. freemium. you.com/platform

Serper — fast Google SERP API. freemium. serper.dev

SerpAPI — SERP scraping across many engines. freemium. serpapi.com

Kagi Search API — premium results + content extract. paid. help.kagi.com

Jina Reader — any URL → clean LLM-ready markdown via r.jina.ai/<url>. open. jina.ai/reader

Jina Search / Embeddings — web search in markdown + embeddings and reranking. freemium. jina.ai

02

Web-to-Data: Scraping as an API

Firecrawl — scrape / crawl / search sites → markdown; hosts the Alexandria gateway. freemium. firecrawl.dev

ScrapingBee — JS rendering + proxies → HTML and data. freemium. scrapingbee.com

Apify — platform of scraper actors + a datasets store. freemium. apify.com

Diffbot — extraction plus a full Knowledge Graph API. freemium. diffbot.com

Common Crawl — open petabyte-scale web archive (WARC). open. commoncrawl.org

03

Scholarly & Structured Data APIs

OpenAlex — graph of ~250M works, authors, institutions. open. openalex.org

Semantic Scholar API — metadata, citations, embeddings, DOI batch. free-key. api.semanticscholar.org

Crossref API — DOI and publication metadata. open. api.crossref.org

Unpaywall — legal open-access full texts by DOI. open. unpaywall.org

CORE — aggregator of 300M+ open-access full texts. free-key. core.ac.uk

DataCite API — DOI metadata for datasets and objects. open. datacite.org

Europe PMC — biomed literature + full texts, REST. open. europepmc.org

arXiv API — preprint metadata (Atom). open. info.arxiv.org/help/api

Papers With Code API — papers ↔ code ↔ SOTA benchmarks (API status shaky since 2025). open. paperswithcode.com

Hugging Face Datasets / Hub — thousands of datasets + rows over API. free-key. huggingface.co

04

Knowledge Graphs & Reference Data

Wikidata — free knowledge graph, SPARQL + REST. open. query.wikidata.org

Wolfram Alpha API — computational knowledge and facts. freemium. wolframalpha.com/api

DBpedia — knowledge graph from Wikipedia, public SPARQL. open. dbpedia.org/sparql

05

The MCP Layer: Catalogues of Connectors

Official MCP Registry — the canonical registry of MCP servers. open. github.com/modelcontextprotocol

mcp.so — the largest public catalogue of MCP servers. open. mcp.so

Smithery / Glama / PulseMCP — directories + hosting for MCP servers. open. smithery.ai

06

RAG & Retrieval Infrastructure

LlamaIndex — indexing and retrieval framework for RAG. open-source. llamaindex.ai

LangChain / LangGraph — chain and agent orchestration + retrievers. open-source. langchain.com

Vector DBs with a free tier — Qdrant, Weaviate, Chroma, pgvector, Milvus. open-source. qdrant.tech

The paywall was never the hard part. The access layer is going quiet-paid — but the open scientific APIs (OpenAlex, Crossref, arXiv, Unpaywall, Europe PMC, Wikidata, Common Crawl) still ask nothing. Build the agent on those, and it stays free.
