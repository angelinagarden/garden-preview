The Access Layer: The Open Data Backbone Every Researcher Can Reach

We scored every tool on one objective scale — openness, uniqueness, scale, durability, fit — and kept only the strong. The result makes an argument by itself.

The strongest access to data is almost perfectly the open access: canonical, institution-backed, free. The paid search wrappers scored lowest and were cut. So here is the open data backbone a researcher — or an agent — can reach right now, grouped by what it unlocks.

open = free, no key. free-key = free, needs a key. freemium = free tier, then paid. open-source = run it yourself.

01

The Open Scholarly Backbone

OpenAlex — graph of ~250M works, authors, institutions (open replacement for Scopus). open. openalex.org

Crossref API — canonical DOI and publication metadata. open. api.crossref.org

arXiv API — preprint metadata across physics, maths, CS, bio. open. info.arxiv.org/help/api

Unpaywall — legal open-access full texts by DOI. open. unpaywall.org

Semantic Scholar API — metadata, citations, embeddings, the S2ORC corpus. free-key. api.semanticscholar.org

Europe PMC — biomed literature plus full texts, REST. open. europepmc.org

CORE — aggregator of 300M+ open-access full texts. free-key. core.ac.uk

OpenCitations — CC0 citation graph, billions of DOI-to-DOI links. open. opencitations.net

DOAJ — index of 23k+ vetted open-access journals + articles. open. doaj.org/api

OpenAIRE Graph — EU open scholarly graph: pubs, data, software, funding. open. graph.openaire.eu

Zenodo — open repository for data, software, papers; CERN-backed. open. developers.zenodo.org

ROR — CC0 identifiers for 146k+ research organisations. open. ror.org

02

Open Scientific Databases (by field)

NCBI E-utilities — one keyless gateway to 35+ NIH databases (PubMed, GenBank, dbSNP). open. ncbi.nlm.nih.gov

UniProt — canonical protein-knowledge API (UniProtKB, ID mapping). open. uniprot.org

PubChem — largest open chemistry DB, 100M+ compounds. open. pubchem.ncbi.nlm.nih.gov

GBIF — world biodiversity layer, ~3.96B occurrence records. open. gbif.org

Ensembl — genome annotation and comparative genomics across species. open. rest.ensembl.org

RCSB PDB — CC0 archive of 254k+ experimental 3D protein structures. open. data.rcsb.org

03

Open World, Society & Web Data

Wikidata — free knowledge graph, SPARQL plus REST. open. query.wikidata.org

World Bank Open Data — 16k+ global development and economic indicators. open. data.worldbank.org

OpenStreetMap / Overpass — canonical open world map + a query engine over the full graph. open. overpass-api.de

GDELT 2.0 — largest open event and news database, 100+ languages, 15-min updates. open. gdeltproject.org

Internet Archive / Wayback — keyless index over every web snapshot ever saved. open. archive.org

Common Crawl — open petabyte-scale web archive (WARC). open. commoncrawl.org

EPO Open Patent Services — European and PCT patent bibliographic, full-text, legal-status data. free-key. epo.org

04

Agent Plumbing: How It Plugs In

Jina Reader — any URL to clean LLM-ready markdown via r.jina.ai/<url>. open. jina.ai/reader

Firecrawl — scrape, crawl and search sites into markdown; hosts the Alexandria gateway. freemium. firecrawl.dev

Diffbot — extraction plus a full Knowledge Graph API. freemium. diffbot.com

Official MCP Registry + mcp.so — canonical registry and catalogue of MCP connectors to data. open. mcp.so

LlamaIndex / LangChain — open-source orchestration and retrievers for RAG. open-source. llamaindex.ai

Vector DBs (free tier) — Qdrant, Weaviate, Chroma, pgvector, Milvus. open-source. qdrant.tech

The pattern is the point. Strength tracked openness almost one to one. The commercial layer is quietly going paid — but this backbone, run by universities, nonprofits and public bodies, still asks nothing. Build on it, and it stays free.
